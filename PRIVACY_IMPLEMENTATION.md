# Optional business information collection

The planner should remain fully usable without registration. The current application saves actions and the organisation name in the visitor's browser only.

Proposed voluntary submission: business name, county, sector, employee-size band, and contact email only where a visitor explicitly requests follow-up. No checklist answers, notes or action-plan content should be transferred with the optional form.

Before enabling submissions: configure restricted private server-side storage and an administrator-only retrieval/deletion process; approve a privacy notice covering controller, purposes, lawful basis, recipients and transfers, retention, withdrawal and rights; add spam and abuse controls; verify the form saves successfully; and keep it unavailable if storage is not configured.

Vercel Web Analytics is not enabled for this project. Enable it separately in the Vercel dashboard if visitor metrics are desired, and review its privacy and billing implications.
